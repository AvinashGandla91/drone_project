# Reference gesture guide

The composite image supplied by the project operator defines the first six classes in this fixed order: LEFT, RIGHT, FORWARD, BACKWARD, LAND, UPWARD. A closed fist is the seventh STOP/HOLD class. The reference image must be retained by the operator during collection and reviewed before recording examples.

Do not replace the fifth LAND reference pose with an assumed conventional gesture. The written brief calls it edge-on, while the supplied composite appears to show an open hand with the palm toward the camera. The operator explicitly chose to follow the image as shown. This ambiguity should be documented during data collection.

LEFT and RIGHT are static pose classifications; no swipe direction or horizontal displacement may be used to select the label. If the relevant shape is ambiguous in camera input, return UNKNOWN.
